Privacy Policy

Effective date: October 21, 2026 · Last updated: October 21, 2026

This policy explains what data the publishing tool of The Story of Everything (the "App") accesses, why, where it is kept and how access can be removed. It also covers this website.

1. Who operates the App

The App and this website are operated by The Story of Everything (the "Operator"), the team behind the channel of the same name. Contact: hikayesidunyanin@gmail.com.

2. What the App is — and is not

The App is a private, single-operator tool that runs on the Operator's own Windows computer. It uploads videos made for The Story of Everything to the channel's own YouTube channel and Instagram account.

  • It is not a public service. There is no sign-up, and no one other than the Operator can sign in.
  • The only Google account that authorizes the App is the Operator's own account that owns the YouTube channel.
  • It does not collect data about viewers, subscribers or commenters of the channel.
  • It has no servers of its own: everything runs on the Operator's computer and talks directly to Google and Meta.

3. Google user data the App accesses

The Operator authorizes the App once through Google OAuth 2.0. The App requests these scopes:

ScopeWhat the App does with it
youtube.uploadUploads the channel's videos and sets their title, description, tags, privacy status and scheduled publish time.
youtube.force-sslUploads the English caption (subtitle) file of each uploaded video.
youtube.readonlyReads the channel's ID and title (to confirm it is connected to the right channel) and the titles of the channel's most recent uploads (to avoid uploading the same video twice after an interrupted upload).

The App does not read or change playlists, comments, subscriptions, analytics, other channels or any non-YouTube Google data.

4. How Google user data is used and shared

  • Data received from Google APIs is used only to publish and manage the channel's own videos as described above.
  • It is not sold, not used for advertising, and not transferred to anyone else.
  • It is not used to develop, improve or train AI or machine-learning models.
  • It is not read by people, except by the Operator when looking at the App's own logs for their own channel.

The App's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

5. What is stored, and where

ItemWhere / how
Google OAuth access and refresh tokenA file on the Operator's computer, encrypted with Windows Data Protection (DPAPI) so that only the Operator's Windows user account on that computer can decrypt it.
Google OAuth client configuration (client ID and client secret of the App)A file on the Operator's computer. This file is not encrypted.
Instagram access tokenA file on the Operator's computer, encrypted with Windows DPAPI.
Publishing logPlain-text files on the Operator's computer that record each upload attempt: time, which account, the video file's checksum, the resulting YouTube video ID / Instagram media ID and link, the scheduled publish time, and error messages.

Nothing is sent to any server operated by the Operator, because there is none. Tokens are sent only to Google (for YouTube) and Meta (for Instagram), over HTTPS, as part of the API calls themselves.

6. Retention and deletion

Current status (stated plainly): the App has no automatic deletion and no fixed retention period. Tokens stay stored until access is revoked or the Operator deletes the files; the publishing log is kept until the Operator deletes it.

  • Google access can be removed at any time at myaccount.google.com/permissions. After that, the stored Google token no longer works.
  • The Operator can delete the stored token and log files manually. Requests can be sent to hikayesidunyanin@gmail.com and are handled by hand.
  • Videos published to YouTube or Instagram are kept by those platforms under their own policies and can be deleted in YouTube Studio or the Instagram app.

7. Security

Tokens are encrypted at rest with Windows DPAPI and are never written to logs or shown on screen. Security therefore also depends on the Operator's Windows account and computer. The App has not been independently audited, and it makes no backups of tokens.

8. Instagram (Meta) and video delivery

For Instagram, the App uses the official Instagram API with Instagram Login for the Operator's own Instagram account. To give Instagram a video, the App makes that single video file reachable for a few minutes through a temporary Cloudflare tunnel at a random, unguessable web address, and closes it once Instagram has fetched the file. During that time the video file passes through Cloudflare's network (Cloudflare Privacy Policy). The video is the channel's own content and contains no personal data. Meta's handling of the account is covered by the Instagram Privacy Policy.

9. YouTube API Services

The App uses YouTube API Services. By using the App, the account owner agrees to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy. Access granted to the App can be revoked through Google's security settings page.

10. This website

This website is a static site hosted on GitHub Pages. It uses no cookies, no analytics, no tracking and no third-party scripts or fonts. GitHub, as the host, may log technical data such as visitors' IP addresses for security purposes; see the GitHub General Privacy Statement.

11. Your rights (GDPR)

The Operator is based in Germany, so the EU General Data Protection Regulation (GDPR) applies. The controller is the Operator named in section 1 (contact: hikayesidunyanin@gmail.com).

  • The App processes the Operator's own account data to run the Operator's own channel. Website hosting logs kept by GitHub are processed on the basis of a legitimate interest in operating a secure website (Art. 6(1)(f) GDPR).
  • You have the right to access, rectification, erasure, restriction of processing, data portability and to object (Art. 15–21 GDPR). Requests are handled by hand via the e-mail address above; there is no automated tool for this.
  • You also have the right to lodge a complaint with a data protection supervisory authority, in particular in the EU member state where you live or work.

12. Children

The App is used only by the Operator and is not directed at children. It does not knowingly collect personal data from anyone, including children.

13. Changes

If the App starts accessing different data or changes how data is stored, this page will be updated and the "Last updated" date changed.
